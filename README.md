# DevPortfolio

A modern and responsive portfolio website built for our three-member development team.

## 📌 About the Project

DevPortfolio is a simple portfolio website created to showcase our team members, skills, resumes, and project information in one place.

The project is being developed using an Agile/Scrum workflow with Jira and GitHub.

## 🎯 Project Goals

- Create a clean portfolio landing page
- Introduce all three team members
- Display technical skills
- Provide resume access
- Build a responsive design for desktop, tablet, and mobile
- Follow a professional Git and GitHub workflow
- Deploy the final project publicly

## ✨ Features

- Responsive navigation bar
- Hero section
- Team member profiles
- Skills section
- Resume access
- Responsive layout
- Mobile-friendly navigation
- Production deployment

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Git
- GitHub
- Jira
- Vercel
